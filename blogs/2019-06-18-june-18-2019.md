Feature Cloud Speech-to-Text now has expanded to a 5 minute limit for streaming recognition . To use streaming recognition with the 5 minute limit, you must use the v1p1beta1 API version. Feature Cloud Speech-to-Text now supports transcription of MP3 encoded audio data .
